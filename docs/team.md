## Collaboration workflow

1. Start a feature branch from the latest main.
2. Keep changes focused on one task.
3. Test the work and push the feature branch.
4. Open a pull request targeting main.
5. Request review from Grace256c.
6. Grace Nakiyemba reviews and merges.

Never commit passwords, API keys or real customer data.

Agree on API request and response formats before integrating components.
Coordinate changes to shared files and database models with the technical lead.
